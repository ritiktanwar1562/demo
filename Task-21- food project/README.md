# Healthy Food Landing Page

## Project Overview

This is a responsive Healthy Food Landing Page made using HTML and CSS. The website is designed to show healthy meal plans, cities, customer reviews and pricing in a simple and attractive way.

## Features

- Responsive design
- Navigation bar
- Hero section
- How It Works section
- Cities section
- Customer testimonials
- Pricing plans
- Footer with social links

## Technologies Used

- HTML5
- CSS3
- Font Awesome

## What I Learned

While making this project, I learned:

- How to create a landing page using HTML.
- How to use CSS for styling.
- How to use Flexbox for layouts.
- How to make a website responsive using media queries.
- How to add icons using Font Awesome.
- How to organize sections in a webpage.
