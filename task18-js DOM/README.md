# JavaScript DOM and Event Handling Task

## Objective

The objective of this task is to create a simple web page using HTML, CSS and JavaScript.

## Features

- Header with greeting message.
- Four color boxes.
- Input field for user name.
- Button to greet the user.
- Box color changes when clicked.

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Learned

Through this task, I learned:

1. How to create a webpage using HTML.
2. How to style elements using CSS.
3. How to select elements using DOM methods.
4. How to use Event Listeners in JavaScript.
5. How to change text dynamically using JavaScript.
6. How to change element styles on user interaction.

## Conclusion

This task helped me understand the basics of DOM Manipulation and Event Handling in JavaScript.
