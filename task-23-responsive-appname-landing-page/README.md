# Responsive AppName Landing Page

## Project Explanation

In this project, I created a responsive landing page using HTML, CSS, and JavaScript.

The landing page includes:
- Responsive Navigation Bar
- Hero Section
- Features Section
- Footer
- Mobile Responsive Design

The layout is created using Flexbox and CSS Grid. Media Queries are used to make the website responsive on mobile devices.



## Technologies Used

- HTML5
- CSS3
- JavaScript



## Files

- index.html
- style.css
- script.js
- README.md



## How to Run

1. Open the project in VS Code.
2. Open index.html.
3. Run it using Live Server.



## What I Did

- Created a responsive navigation bar.
- Designed a hero section with heading, text, button, and image.
- Built a features section using CSS Grid.
- Added a footer with basic information.
- Used Flexbox and Media Queries to make the page responsive.
- Linked HTML, CSS, and JavaScript files together.



## What I Learned

- How to create a responsive landing page.
- How to use Flexbox for layouts.
- How to use CSS Grid for feature cards.
- How to use Media Queries for different screen sizes.
- How to connect HTML, CSS, and JavaScript files.
- Improved my understanding of responsive web design.



## Conclusion

This project helped me practice responsive web design using HTML, CSS, and JavaScript. I learned how to create a clean landing page that works well on desktop and mobile devices.
