# JavaScript Map Filter Exercise

## Project Overview

This project displays student records using HTML, CSS and JavaScript.

Each student record contains Name, Marks, Class and Address.

A search box is provided to search students by name.

---

## Features

- Display student records in card format
- Search students by name
- Real-time filtering
- Used JavaScript Map Function
- Used JavaScript Filter Function

---

## What I Did

In this assignment, I created an array of student objects.

I displayed all student records dynamically using the JavaScript map() function.

I created a search box where users can search students by name.

I used the filter() function to show only matching student records.

The student cards update automatically when the user types in the search box.

- How to use the filter() function
