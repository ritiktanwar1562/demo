# Thala 7 Sneaker Store

This is a simple sneaker store website created using HTML and CSS. I made this project to practice basic web development concepts and improve my frontend development skills.

## Features

- Navigation bar for easy access
- Hero section with heading, text and button
- Sneaker image display
- Service section showing reviews, customers and ratings
- Clean and simple user interface

## Files Used

- index.html – website structure
- style.css – website styling
- shoe.png – sneaker image used in the hero section
- README.md – project documentation
- product.html- product informatiom
- cart.html-  procduct order
- payment.html- product payment

## What I Learned

While creating this project, I learned how to build a basic website using HTML and CSS. I practiced creating different sections, adding images, styling elements, and arranging content using Flexbox.

I also understood how HTML provides the structure of a webpage while CSS is used to improve its appearance and layout.

During the project, I faced some difficulty in adding and resizing the image correctly, but after making a few changes in the CSS file, I was able to display it properly.

## How to Run

1. Download all project files.
2. Open the project folder.
3. Open index.html in any web browser.

## Conclusion

This project helped me understand the fundamentals of web development and gave me hands-on experience in designing a simple webpage using HTML and CSS.
