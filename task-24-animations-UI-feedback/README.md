# Animations & UI Feedback

## Project Overview

I made this project to practice animations and interactive UI using HTML and Tailwind CSS.

In this project, I created different animation examples like built-in animations, button hover effects, card animations, notification badges, and loading animations. The purpose was to understand how animations can improve the user experience.



## Features

- Built-in Tailwind animations
- Button hover effects
- Interactive animation cards
- Notification badges
- Loading state animations
- Responsive layout for different screen sizes

## Technologies Used

- HTML5
- Tailwind CSS



## What I Learned

While making this project, I learned:

- How to use Tailwind CSS animation classes.
- How hover and active effects work.
- How to create simple interactive UI.
- How to use transitions for smooth animations.
- How responsive layouts are created using Tailwind.



## Challenges I Faced

At first, I was confused about choosing the correct Tailwind animation classes and arranging the layout properly. I also had to adjust spacing and alignment so every section looked clean. After trying different classes and making small changes, I completed the project successfully.



## Conclusion

This project helped me understand how animations make a website more interactive and attractive. It also improved my confidence in using Tailwind CSS for building modern user interfaces.
