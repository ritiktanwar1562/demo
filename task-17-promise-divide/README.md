# Promise Based Divide Function

## Project Objective

This project is based on JavaScript Promises. The goal is to divide two numbers and handle errors when the second number is zero.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Divide two numbers
- Uses Promise
- Uses Arrow Function
- Handles division by zero
- Tested with 5 different cases

## What I Did

- Created a divide function using arrow syntax.
- Returned a Promise from the function.
- Used resolve() when division was successful.
- Used reject() when the second number was zero.
- Displayed the results using console and browser output.
- Tested the function with different values.

## What I Learned

From this project I learned:

- How Promises work in JavaScript.
- How to use resolve() and reject().
- How to handle errors using catch().
- How to create Arrow Functions.
- How to test multiple cases in JavaScript.

## Conclusion

This project helped me understand Promise handling and error management in JavaScript.
