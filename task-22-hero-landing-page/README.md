# Hero Landing Page

## Project Description

This is a simple Hero Landing Page created using HTML and Tailwind CSS.

The main purpose of this project is to learn how to create a modern landing page using Tailwind CSS utility classes.



## Features

- Sticky Navigation Bar
- Hero Section
- Gradient Background
- Call to Action Buttons
- Dashboard Preview
- Floating Cards
- Chat Button
- Responsive Design



## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript



## What I Learned

While creating this project, I learned:

- How to use Tailwind CSS.
- How to create a sticky navbar.
- How to use Flexbox for alignment.
- How to add spacing using Tailwind classes.
- How to create buttons using Tailwind.
- How to use relative and absolute positioning.
- How to create a fixed chat button.
- How to build a simple responsive landing page.



## Folder Structure

## How to Run

1. Download the project.
2. Open the project folder.
3. Open the index.html file in your browser.
4. The Hero Landing Page will be displayed.



## Conclusion

This project helped me understand the basics of Tailwind CSS and responsive web design. It also improved my knowledge of layout, spacing, positioning, and creating a clean landing page.
