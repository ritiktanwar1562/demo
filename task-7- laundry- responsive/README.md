# Laundry Services Responsive Website

## Project Overview

This project is a simple responsive laundry services landing page created using HTML and CSS. The main goal of this task is to make the webpage responsive for desktop, tablet, and mobile devices using CSS Media Queries.

---

## Features

- Responsive Navbar
- Hero Section with heading, description and button
- Laundry image in Hero Section
- Flexbox layout
- Mobile-friendly design
- Tablet responsive layout
- Navigation links hidden on mobile view
- Logo and Username visible on mobile
- Pure HTML and CSS (No Bootstrap)

---

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries

## What I Did

- Created a responsive navigation bar using Flexbox.
- Designed the hero section with text, button and image.
- Added media queries for tablet and mobile screens.
- Reduced text and image sizes for smaller devices.
- Changed the hero section layout to column on mobile.
- Hid navigation links on mobile and displayed only Logo and Username.
