# FlowApp - SaaS Landing Page

## About

I made this project as part of a Tailwind CSS mini challenge. The goal was to build a modern SaaS landing page using HTML and Tailwind CSS while practicing layouts, responsive design, hover effects, and animations.

## Features

- Responsive Navbar
- Hero Section
- Dashboard Preview
- Features Section
- Testimonials Section
- Call To Action Section
- Footer
- Hover Effects
- Gradient UI
- Glassmorphism Design
- Responsive Layout

## Technologies Used

- HTML5
- Tailwind CSS
- Font Awesome

## What I Learned

- Responsive Design
- Flexbox & Grid
- Tailwind CSS Utilities
- Hover Effects
- Glassmorphism
- Gradient Backgrounds
- Basic Animations
- UI Layout Design

## Project Challenge

This project was built by following a SaaS Landing Page challenge. I tried to recreate the given design while improving my Tailwind CSS and frontend skills.
