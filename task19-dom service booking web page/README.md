# Service Booking Web App

## About Project

This is a Service Booking Web App made using HTML, CSS and JavaScript.

In this project, users can see different services, add services to the cart, check the total amount and book the selected services.

## Features

- Navigation Bar
- Service Cards
- Add Item Button
- Skip Item Button
- Added Items List
- Total Amount Calculation
- Booking Form
- Booking Successful Message

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Did

- Created the webpage structure using HTML.
- Designed the page using CSS.
- Added different service cards.
- Created Add Item and Skip Item buttons.
- Used JavaScript DOM to add services dynamically.
- Updated total amount when items were added.
- Created a booking form for users.
- Displayed a booking success alert after booking.

## How to Run

1. Download the project files.
2. Open the project folder.
3. Open index.html in your browser.
4. Add services and test the booking process.
