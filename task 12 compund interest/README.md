# Compound Interest Calculator

## About Project

I made this project using HTML, CSS and JavaScript.

This project calculates compound interest using predefined values and displays the result in the browser console.

## What I Learned

- How to create variables in JavaScript
- How to use operators
- How to use the compound interest formula
- How to use Math.pow()
- How to display output using console.log()
- How to link HTML, CSS and JavaScript files

## Files Used

1. index.html
2. style.css
3. script.js
4. README.md

## Output

The program calculates the compound interest and shows the result in the console.
