# Even Odd Checker

## Objective

This project checks whether a number is even or odd using JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Learned

Through this task I learned:

- How to take input from the user.
- How to use variables in JavaScript.
- How to use if-else statements.
- How to check conditions using the modulus (%) operator.
- How to display output on the webpage.
- How to print output in the browser console.

## How It Works

1. User enters a number.
2. Clicks the Check button.
3. JavaScript checks whether the number is divisible by 2.
4. The result is displayed on the screen and in the console.

## Output

- The number 5 is odd.
- The number 10 is even.
