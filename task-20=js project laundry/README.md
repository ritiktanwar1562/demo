# Laundry Service Website

## About Project

I created this Laundry Service Website using HTML, CSS and JavaScript. This website helps users book laundry services online. Users can add services, check the total amount and book a service.

## Features

- Navigation Bar
- Hero Section
- Laundry Services Section
- Add Item Feature
- Total Amount Calculation
- Booking Form
- Newsletter Section
- Footer Section

## Technologies Used

- HTML
- CSS
- JavaScript
